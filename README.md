# JavaScript Platform

Assignments and exercises for the **Platform-Based Programming (Pemrograman Berbasis Platform)** course, which I took in semester 4. Each `Week-N` folder holds the exercise or assignment I did for that session, following the course order from JavaScript basics to building a backend API.

## Course Topics by Week

| Week | Topic |
|---|---|
| 1 | Introduction |
| 2 | JavaScript Basic and Fundamentals |
| 3 | Branching, Looping, and Array |
| 4 | Object Literal |
| 5 | Module and Package |
| 6 | Web Server |
| 7 | Basic Routing and Advanced Routing |
| 8 | Midterm (UTS) |
| 9 | Databases |
| 10 | API Endpoint |
| 11 | Middleware |
| 12 | Accessing Public API and Validation |
| 13 | JSON Web Token (JWT) Authentication |
| 14 | Unit and Integration Testing |
| 15 | Final Project |
| 16 | Final Exam (UAS) |


## Tech Used

- JavaScript (Node.js)
- Web server and routing
- Database
- REST API with middleware and validation
- JWT authentication
- Unit and integration testing

## How to Run a Project

```bash
cd Week-N/project-folder
npm install
npm start
```

For projects with tests:

```bash
npm test
```
